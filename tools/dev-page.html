Windhawk UI translator - page engine dev harness

The stub below fakes window.chrome.webview and answers the settings? and http messages with canned Microsoft-style Edge responses. The engine is loaded from ../src/js/engine.js. Hover a translated block to see the original, move away to restore the translation. On touch, tap a block to toggle it; two-finger double tap anywhere toggles translation globally.

Windhawk UI Translator

This mod translates mod descriptions and settings into your language.

Install the mod with windhawk-cli mod install and restart the app.

  • Read the documentation first.
  • Enable the settings scope.
Translations are cached locally.
